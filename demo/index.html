What this demo is

  • The real scanner element and the same matching code the server uses, running in this browser instead.
  • Foot measurements are kept in this browser only. No photos or video are stored.
  • Real logins use the verification service, so nobody can edit the result in the page.

Using your own feet

  • Live camera needs https or localhost. Embedded previews that block the camera can still run Sample feet.
  • With Sample feet on a computer, "Use my phone" shows a simulated phone below the scanner. With the real service, the QR code opens it on your phone.
  • Socks off, trousers on: only the foot should be bare. A plain floor that contrasts with your skin works best.
